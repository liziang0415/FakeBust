How should the analysis flow work?

After the user submits, what happens next?

Flow A — Redirect to Report Page
① Home (input)
→ submit →
② Loading spinner
→
③ /report/[uuid]
Report page shows:
🔴 LIKELY FAKE — 78%
+ reason paragraph
+ 3 flagged quotes from article
🔗 Share: fakebuster.app/report/abc123

A — Redirect to Report (Recommended)

Submit → loading → redirected to unique report URL. Report page is the permanent shareable link. Clean, simple, every analysis gets its own page.

Flow B — Inline Results + Generate Link
① Home (input)
→ submit →
② Verdict slides in below
🔴 LIKELY FAKE — 78%
brief reason

B — Inline Verdict + Share Button

Result appears below the input box; user stays on home page. "Full Report" opens in a new page or modal. "Copy Link" generates the shareable URL on demand.

Flow C — Streaming Analysis
① Home
→
② Gemini streams word-by-word
Analyzing article...
Detected language: Chinese
Verdict forming: 🔴 FAKE▌
Key red flag: "statistics cannot be verified..."

C — Streaming (word-by-word)

Gemini response streams in real-time — users see the analysis build up live. More engaging but complex to parse reliably and harder to store in MongoDB atomically.
