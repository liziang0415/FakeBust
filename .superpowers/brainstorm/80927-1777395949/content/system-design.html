Gemini Prompt Strategy
Single prompt → structured JSON output
Gemini is instructed to respond ONLY in JSON, regardless of the input language. The prompt asks it to: detect the language, assess each key claim, return verdict + confidence + reason + up to 5 flagged quotes with warnings. JSON mode (response_mime_type: "application/json") ensures parseable output every time.
